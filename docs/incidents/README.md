# Incident Documentation

When a source fails validation or causes issues in production, document here.

## Template

```markdown
# Incident: [Source Name] [Issue]

**Date:** YYYY-MM-DD  
**Source:** [whois|site_monitoring|google_trends]  
**Status:** [Disabled|Investigating|Mitigated]

## What Happened

[Description of the failure]

## Actions Taken

- [Action 1]
- [Action 2]

## Resolution

[How it was resolved or why it remains disabled]

## Lessons Learned

[What to avoid or watch for in the future]
```
